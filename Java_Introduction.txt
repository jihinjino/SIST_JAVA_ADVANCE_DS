1. WHAT IS JAVA?
---------------------------------------------------------

Definition:
Java is a high-level, object-oriented, platform-independent
programming language developed by Sun Microsystems
(now owned by Oracle).

Features:
• Simple
• Object-Oriented
• Platform Independent
• Secure
• Robust
• Multithreaded
• Portable
• Distributed
• Dynamic

Java follows the principle:

"Write Once, Run Anywhere (WORA)"

---------------------------------------------------------
2. HISTORY OF JAVA
---------------------------------------------------------

• Developed by James Gosling in 1995.
• Originally called Oak.
• Later renamed Java.
• Owned by Oracle Corporation.

1. Java SE (Standard Edition)

2. Java EE (Enterprise Edition)

---------------------------------------------------------
4. JDK, JRE, JVM
---------------------------------------------------------

JDK (Java Development Kit)
--------------------------
Used to develop Java applications.

Contains:
• JRE
• Compiler (javac)
• Debugger
• Development Tools

JRE (Java Runtime Environment)
------------------------------
Used to run Java programs.

Contains:
• JVM
• Library Files

JVM (Java Virtual Machine)
--------------------------
Responsible for executing Java Bytecode.

Functions:
• Loads bytecode
• Verifies code
• Executes program
• Provides platform independence

Flow:

Java Program (.java)
       ↓
Compiler (javac)
       ↓
Bytecode (.class)
       ↓
JVM
       ↓
Output

---------------------------------------------------------
5. FIRST JAVA PROGRAM
---------------------------------------------------------

Syntax:

public class Main
{
    public static void main(String[] args)
    {
        System.out.println("Hello World");
    }
}

Output:
Hello World

Explanation:

public
    Access modifier

class
    Keyword to create class

Main
    Class name

main()
    Entry point of program

System.out.println()
    Prints output with newline

7. VARIABLES
---------------------------------------------------------

Definition:
A variable is a container used to store data.

Syntax:

datatype variableName;

Example:

int age = 20;

Rules:
• Cannot start with number
• No spaces
• Cannot use keywords
• Case-sensitive

Examples:

int studentAge = 21;
double salary = 25000.50;
char grade = 'A';

13. ARITHMETIC OPERATORS
---------------------------------------------------------

Operator      Meaning

+             Addition
-             Subtraction
*             Multiplication
/             Division
%             Modulus

int b = 10;

System.out.println(a+b);
System.out.println(a-b);
System.out.println(a*b);
System.out.println(a/b);
System.out.println(a%b);

10
200
2
0

20. IMPORTANT INTERVIEW QUESTIONS
---------------------------------------------------------

Q1. Difference between JDK, JRE and JVM?

JDK -> Development
JRE -> Execution
JVM -> Runs Bytecode

--------------------------------

Q2. Why Java is Platform Independent?

Because JVM executes bytecode on every operating system.

--------------------------------

Q3. Why main() is static?

Because JVM calls it without creating an object.

--------------------------------

Q4. Difference between float and double?

float  -> 4 Bytes
double -> 8 Bytes

double is more precise.
